Github Actions
- CI/CD Platform that allows you to build, test and deploy pipelines(automated workflows)
- More than just DevOps -> Events eg workflow that adds release notes || labels whenever a PR

Components of Github Actions
1. Workflows 
    - A workflow is automated process aimed at running one or more jobs
    - Defined YAML/yml
    - defined in afolder called .github/workflows
    - Repo can have multiple workflows

2. Events - an activity in the repo that will trigger a workflow

3. Jobs - these are steps in a workflow 

4. actions - predefined, reusable set of jobs to perform a specific task. eg -> eg an action to login to a remote server

5. Runners - a server that runs your workflows whenever theyre triggered
